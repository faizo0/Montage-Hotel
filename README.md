# THE MONTAGE SIGNATURE HOTEL — Frontend Foundation (Step 1)

Architectural frontend foundation for **THE MONTAGE SIGNATURE HOTEL**, an international five-star luxury hotel public experience and executive hotel management dashboard.

## Light Luxury Design System

- **Warm Ivory**: `#F8F6F0` (Primary canvas)
- **Soft Cream**: `#F1EDE4` (Structural surface)
- **Champagne Beige**: `#E8DFD0` (Hairline borders & tactile highlights)
- **Deep Forest Green**: `#244B45` (Primary action & brand anchor; hover `#183A35`)
- **Soft Sage**: `#E8EFEA` (Secondary button surface & subtle callout surface)
- **Charcoal Typography**: `#292D2B` (Primary text)
- **Muted Grey**: `#858782` (Secondary metadata & captions)

## Core Stack

- React 19 + Vite
- Tailwind CSS v4
- React Router DOM (Public & Admin route separation)
- GSAP + ScrollTrigger & Lenis Smooth Scroll
- Framer Motion (`framer-motion`)
- Three.js + React Three Fiber (`@react-three/fiber`)
- Recharts & Lucide React

## Scripts

```bash
npm run dev      # Start Vite dev server on port 3000
npm run build    # Production bundle output to dist/
npm run preview  # Preview production build
```
